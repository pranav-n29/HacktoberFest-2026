# CheckMyTOC

Understand before you agree.

CheckMyTOC is an AI-powered Chrome extension that helps users understand Terms and Conditions through plain-English explanations, evidence-backed risk findings, potential consequences, and an explainable risk score.

## Features

- Extract terms from a webpage after user action
- Analyze privacy, payments, renewal, cancellation, liability, and other clauses
- Explain findings in plain English
- Show evidence supporting each finding
- Generate a transparent risk score
- Provide an agreement checklist

## Tech Stack

- Chrome Extension — Manifest V3
- HTML, CSS, JavaScript
- Node.js and Express
- Gemma 4 through the supported Gemini API
- Rule-based risk scoring
